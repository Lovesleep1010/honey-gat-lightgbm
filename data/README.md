# Dataset

**Hyperspectral Imaging adulterated honey dataset** (version 1, 2021), by Tessa Phillips, Bradley Coleman, Shunji Takano and Waleed Abdulla.

[Source and DOI](https://doi.org/10.17608/k6.auckland.16441686.v1) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The included `adulteration_dataset_26_08_2021.csv` is unmodified. Label selection and the C4/ManukaUMF10/50% exclusion are applied in the data loader. Retain this attribution when redistributing the dataset.
